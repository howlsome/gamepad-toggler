# Changelog

## v1.0.0

First public release.

- Per-character Gamepad UI on/off for World of Warcraft: Forever, stored account-wide.
- Settings page under Options > AddOns, opened with `/gpt`, listing every character with a checkbox.
- Full Forever names (first name and surname) in class colours, with the ruleset: Normal, PvP, Roleplay, Roleplay PvP or Hardcore.
- Default setting for new characters, and a Remove button for deleted characters.
- Reload prompt with a Reload UI button when the setting changes, since Forever blocks addons from reloading the UI directly.
- Stays in sync when Gamepad UI is changed from Blizzard's own options.
- Slash commands: `/gpt on`, `/gpt off`, `/gpt toggle`, `/gpt status`.
